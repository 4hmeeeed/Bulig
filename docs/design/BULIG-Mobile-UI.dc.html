CAPSTONE PROTOTYPE · BARANGAY 88, TACLOBAN CITY

BULIG — offline-first emergency reporting

A resident files a report with no internet and no cell signal. The report is held on their phone and relayed phone-to-phone over Bluetooth until some phone finds signal and hands it to the barangay command center. Delivery is opportunistic, so the interface never claims more than it knows.
